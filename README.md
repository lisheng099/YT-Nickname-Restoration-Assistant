# YT 暱稱還原助手（觀眾版擴充功能）

給 YouTube 觀眾使用的 Chrome / Edge 擴充功能，**完全本機運作、免登入、不上傳也不向外部伺服器取得任何資料**。

---

## 主要功能

- **聊天室與留言區暱稱還原**：將 `@handle` 還原為真實頻道顯示名稱，適用於直播聊天室、聊天重播、影片留言區與 YouTube Studio。
- **只佔用名稱**：在直播聊天室滑鼠移到觀眾名稱上，可看到原頻道名稱、訂閱數、會員月份與備註；頭像維持 YouTube 原本的功能。
- **本機自訂暱稱**：在直播聊天室**點擊觀眾的名稱**，即可為對方設定自訂暱稱，聊天室會直接替換顯示為你的自訂暱稱（保留原本會員顏色，滑鼠移上可看原頻道名）。
- **本機填寫備註**：在同一面板中可為對方記錄多筆個人備註，有備註時名稱旁會出現 📝，滑鼠移到名稱上即可預覽，不干擾聊天室原本的閱讀畫面。
- **觀眾資料頁**：頻道名稱快取與自訂暱稱、備註合成一份清單，可用名稱、@handle、頻道 ID、暱稱或備註搜尋，每列直接編輯，也能手動新增觀眾；兩種資料仍分開以 JSON 匯入／匯出。
- **訂閱數小圓點徽章**：名稱旁以色點標示訂閱規模，滑鼠移上可看資訊卡，開啟後點擊名稱可複製頻道連結。
- **統一淺色／暗黑／跟隨系統主題**：所有擴充功能視窗、管理頁面與聊天室筆記面板同步切換外觀主題。

> 若你是直播主，需要跨電腦同步、AI 觀眾記憶整理、自訂彩色標籤與場次精華時間軸，請安裝「StreamMemo 創作者擴充功能」。

---

## 隱私說明

- **100% 本機運作**：頻道名稱由你的瀏覽器直接向 YouTube 查詢並快取在本機；你設定的自訂暱稱與備註獨立儲存在你的瀏覽器中，不會上傳至任何伺服器，清除頻道名稱快取時也不會遺失。

---

## 安裝與設定

1. 開啟 `chrome://extensions`（Edge 為 `edge://extensions`）→ 開啟右上角「開發人員模式」→ 點選「載入未封裝項目」→ 選擇解壓縮後的擴充功能資料夾（或從擴充功能商店安裝）。
2. 重新整理 YouTube 分頁即可生效。
3. 點擊工具列圖示可調整：
   - **語言切換**（繁體中文 / 简体中文 / English / 日本語）
   - **外觀主題**（跟隨系統 / 淺色模式 / 暗黑模式）
   - **名稱最大長度**（5–50，預設 20）、**過期天數**與**自動刪除天數**
   - **自訂暱稱與備註開關**（預設開啟）、**點擊複製連結**、**雙節點替換**與**查詢速度模式**

---

## 注意事項

- 同一個瀏覽器設定檔請勿同時啟用「創作者版」與「觀眾版」，避免重複改寫聊天室名稱。
