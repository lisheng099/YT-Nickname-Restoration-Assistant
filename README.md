# YT 暱稱還原助手（純本地版 / StreamMemo 共用核心）

Chrome / Edge Manifest V3 擴充功能（`v2.0.1`），**永久免費、零雲端連線、所有資料僅存於你的瀏覽器本機**。

---

## 主要功能

- **YouTube 暱稱即時還原**：將聊天室、留言區與重播中的 `@handle` 還原為頻道顯示名稱，保留原有身分顏色與徽章（雙節點替換模式），並以圓點標示頻道訂閱規模。
- **本機觀眾筆記系統**：點擊聊天室觀眾頭像（或名稱旁 `✎`）即可編輯：
  - **自訂暱稱**：直接取代聊天室原本顯示的名稱。
  - **自訂彩色標籤**：於聊天室名稱旁顯示彩色標籤。
  - **計數留言反應**：在管理頁自訂「視窗顯示簡稱／自家頻道貼圖 ↔ 後台詞語」（例如 `冷 ↔ 冷笑話`），同一則留言限點 1 次（再點取消或自動切換），僅採集自家頻道且限 YouTube 官方圖片網域白名單。
  - **觀眾備註**：紀錄細節但不於聊天室顯示 `📌` 干擾畫面，可於頭像面板、📋 迷你面板或管理頁隨時查閱。
- **備份與資料管理**：支援 JSON 匯出／匯入（合併或取代模式），並保留 `UC...` 頻道 ID。
- **熔斷保險絲**：偵測到異常或速率限制時自動暫停抓取，避免影響正常觀看。

> 若需要跨電腦自動雙向同步、多頻道管理與收播後 AI 記憶整理，請參考 [StreamMemo](https://github.com/lisheng099/StreamMemo)（創作者雲端版與此專案共用核心，由 `extension/scripts/sync-core.mjs` 同步）。

---

## 安裝

1. 開啟 `chrome://extensions`（Edge 為 `edge://extensions`）。
2. 開啟右上角「開發人員模式」→「載入未封裝項目」→ 選擇本專案資料夾。
3. 重新整理 YouTube 分頁即可使用。

---
