📺 YT 暱稱還原助手

📖 簡介
YT 暱稱還原助手 是一款專為 YouTube 觀眾設計的瀏覽器擴充功能。為了解決 YouTube 將使用者名稱改為難以辨識的 Handle 代碼（例如 @User-xk9lp...）的問題，本工具會在直播聊天室與影片留言區自動將這些代碼「還原」為真實的頻道顯示名稱，並支援為常客設定本機專屬的自訂暱稱與備註。

我們堅持「完全本機運作、隱私優先」原則：名稱查詢由您的瀏覽器直接向 YouTube 公開的頻道頁面進行（不附帶您的登入 Cookie），不會上傳任何資料到開發者或任何第三方伺服器。

🚀 主要功能

1. 自動還原頻道名稱
- 支援範圍：直播聊天室（含聊天重播）、影片留言區與 YouTube Studio。
- 運作方式：觀看影片或直播時，擴充功能會自動辨識畫面上的 @Handle 代碼，並在背景查詢對應的真實頻道名稱進行替換。
- 保留原生樣式：開啟「雙節點替換」（預設開啟）時，會保留 YouTube 原本的名稱顏色、會員與頻道主樣式。
- 智慧快取管理：查詢過的名稱預設保存在本機 15 天，過期後會在背景自動更新；超過 30 天未更新的資料則會自動清理，不佔用空間。

2. 本機自訂暱稱與備註
- 只佔用名稱：在直播聊天室（含聊天重播與 YouTube Studio 聊天室）、影片留言區與 Shorts 留言區滑鼠移到觀眾名稱上，即可看到原頻道名稱、訂閱數、會員月份與備註；點擊名稱開啟專屬筆記視窗（可於設定面板自由開關，預設開啟）。頭像維持 YouTube 原本的功能。
- 自訂暱稱：為常客設定好記的綽號（最多 40 字），直播聊天室與留言區中會直接替換顯示為您的自訂暱稱（保留原本會員顏色，滑鼠移上可看原頻道名）。
- 個人備註：為每位觀眾新增或刪除文字備註（最多 50 則，每則最多 500 字）；有備註時名稱旁會出現小小的 📝，滑鼠移到名稱上即可預覽。
- 一份觀眾清單：「觀眾資料」頁把頻道名稱快取與您的暱稱、備註合成一份清單，可用名稱、@handle、頻道 ID、暱稱或備註搜尋，每一列都能直接編輯，也能輸入 @handle、頻道 ID 或頻道網址手動新增觀眾（適合下播後補寫備註）。
- 完全私密保存：獨立儲存在您的瀏覽器本機，絕不上傳；即使清除頻道名稱快取，自訂暱稱與備註也會完整保留。

3. 智慧資訊卡
滑鼠移到還原後的名稱上，即可查看懸浮資訊卡：
- 完整頻道名稱：不受長度截斷限制，一眼看清全名。
- 原始 @Handle：方便核對原本的帳號代碼。
- 訂閱數與等級標記：顯示訂閱人數，並在名稱旁依頻道訂閱規模顯示不同顏色圓點：
  🟢 青色：百萬訂閱（1M+）
  🟡 金色：十萬訂閱（100k+）
  ⚪ 銀色：萬人訂閱（10k+）
  🟠 銅色：千人訂閱（1,000+）
  🟤 褐色：潛力頻道（500+）
- 過期提醒：若資料已過期，會在資訊卡提示並於背景自動更新。

4. 豐富偏好設定（點擊工具列圖示）
- 多語系切換：支援繁體中文、簡體中文、英文與日文即時切換。
- 外觀主題切換：支援「跟隨系統」、「淺色模式」與「暗黑模式」，設定視窗、觀眾資料頁與聊天室筆記視窗統一套用。
- 名稱最大長度：自訂顯示字數上限（5–50 字，預設 20 字），避免過長名稱破壞聊天室版面。
- 點擊複製連結：開啟後，點擊還原後的名稱即可複製對方頻道網址（直播聊天室與留言區開啟自訂暱稱與備註時，改用筆記視窗裡的 🔗）。
- 雙節點替換：保留 YouTube 原本的名稱顏色與會員樣式（變更後需重新整理頁面）。
- 自訂暱稱與備註開關：可依需求隨時開啟或關閉點擊名稱編輯與自訂暱稱顯示。
- 抓取頻率控制：提供「普通」與「慢速 (安全模式)」，依觀看習慣自由調整。
- 快取過期天數與自動刪除天數皆可自訂。

💾 匯入與匯出：社群同好必備工具
在「觀眾資料」頁中，您可以將收集到的頻道名稱匯出成 JSON 檔，與同好社群互相分享。

使用方式：
1. 點擊瀏覽器右上角的擴充功能圖示。
2. 點擊「📋 開啟觀眾資料頁」。
3. 點擊「匯出」下載本機名單，或點擊「匯入」載入他人分享的名單並自動合併。
4. 自訂暱稱與備註在頁面底部「備份與清除」另外匯出／匯入；匯入時會與現有資料合併，備註會合在一起，不會刪除任何資料。

🤝 為什麼推薦使用匯入功能？
- 社群共建「常客名單」：老觀眾可將累積的名單分享到粉絲社群，新觀眾匯入後立刻認出聊天室裡的常客。
- 秒速顯示免等待：名單裡已有的帳號在熱門聊天室中會立即顯示名稱，無須逐一等待查詢。
- 安全匯入：選擇「安全匯入 (標記為過期)」時，匯入的資料會先立即顯示，並在該名稱出現於畫面時於背景重新核對。

🛠️ 常見問題

Q1：為什麼有些名稱下方有虛線底線？
A：代表該筆資料是以「安全匯入」匯入的，或已超過過期天數（預設 15 天）未更新。完全不影響閱讀，下次該名稱出現時會自動在背景更新。

Q2：如果名稱沒有還原怎麼辦？
A：短時間內查詢大量新帳號時，可能會被 YouTube 暫時限制，擴充功能會自動放慢查詢速度。若連續查詢失敗，會暫停新的查詢，已快取的名稱仍會照常顯示。請稍候幾分鐘，再打開擴充功能視窗點擊「⚠️ 後端保險絲 (爬蟲)」重新開啟。若習慣長時間掛台，建議在設定中切換為「慢速 (安全模式)」。若反覆發生，可能是 YouTube 改版，歡迎透過視窗中的「🐦 回報問題」告訴我們。

Q3：我的自訂暱稱、備註或瀏覽紀錄會被上傳嗎？
A：不會。本擴充功能只會連線到 YouTube 查詢頻道名稱；名稱快取、自訂暱稱與備註都只存在您的瀏覽器中。匯出的 JSON 檔也只會儲存在您自己的電腦中。
