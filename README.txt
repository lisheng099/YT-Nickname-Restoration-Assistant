# YT 暱稱還原助手 (YT Nickname Restoration Assistant)

版本：2.0.1　｜　原始碼：https://github.com/lisheng099/YT-Nickname-Restoration-Assistant

## 這是什麼

給 YouTube 觀眾與主播使用的 Chrome / Edge 擴充功能，完全在你的瀏覽器內運作，不需要帳號、伺服器或 OBS。

1. 暱稱還原：把聊天室與留言區的帳戶代稱 (@handle，例如 "@user-xyz123") 換成該頻道的顯示名稱。
2. 觀眾筆記：在直播聊天室的名稱旁直接貼標籤、寫備註、加減評分、設定自訂暱稱，下次這位觀眾發言時就看得到。

## 隱私承諾：本地運作、不傳輸資料

- 唯一的網路請求是向 YouTube 讀取頻道頁 (https://www.youtube.com/@handle) 以取得頻道名稱與訂閱數，由你的瀏覽器直接發出，不經過任何第三方伺服器。
- 暱稱快取、標籤、備註、評分、自訂暱稱與設定都儲存在這個瀏覽器 (IndexedDB 與 chrome.storage.local)，不會上傳到任何地方。
- 權限只有 "storage"，以及 "https://www.youtube.com/*" 與 "https://studio.youtube.com/*" 兩個網域。
- 資料只有在你自己按下「匯出」時才會離開瀏覽器，而且是存成你電腦上的 JSON 檔案。
- 專案內的自動測試 (tests/local_only.test.js) 會檢查權限清單，以及程式中沒有連到 YouTube 以外的管道。

## 主要功能

### 暱稱還原
- 適用位置：直播聊天室、聊天重播、彈出式聊天室、YouTube 直播控制室 (Studio) 內的聊天室、影片留言區，以及內文中的 @提及、Super Chat、付費貼圖、會員與禮物訊息的名稱。
- 本地快取：查過的名稱存在本機，預設 15 天後標記為過期並在下次遇到時更新，30 天後刪除；兩個天數都可以調整。
- 訂閱數標記：名稱旁的色點表示訂閱規模（青色 100 萬以上、金色 10 萬以上、銀色 1 萬以上、銅色 1000 以上、褐色 500 以上）；滑鼠移到名稱上可看資訊卡。
- 雙節點替換（預設開啟）：保留 YouTube 原本的名稱節點並隱藏，另外插入暱稱節點，沿用頻道擁有者、管理員等原本的顏色。
- 點擊複製連結：開啟後，點名稱可複製該頻道的網址。
- 暱稱快取管理頁：搜尋、標記過期、刪除、指定重新抓取，以及 JSON 匯出與匯入（匯出檔附 SHA-256 檢查碼；匯入可選「信任」或「安全」模式）。
- 保險絲：畫面替換或資料抓取連續出錯時自動暫停，避免影響瀏覽；可在彈出視窗查看狀態並手動復歸。

### 觀眾筆記（2.0.0 新增）
- 編輯：在直播聊天室把滑鼠移到訊息上，按名稱旁的 ✎，可以：
  - 設定自訂暱稱（聊天室改顯示這個暱稱，滑鼠移上去可看到原本的名稱）
  - 加減評分（每次 +1 或 -1，可歸零）
  - 貼上或新增標籤（可自訂顏色）
  - 寫備註（輸入後按 Enter 新增，可逐則刪除）
- 顯示：有筆記的觀眾發言時，名稱旁會出現標籤、評分與 📌 備註記號（滑鼠移上去可看備註內容）。
- 📋 面板：聊天室右下角的 📋 可展開「最近發言」（最近發言且有筆記的觀眾）與「評分榜」。面板直接顯示在聊天室頁面上，不需要另外開 OBS 停駐視窗。
- 觀眾筆記管理頁：搜尋、排序、新增與編輯觀眾，管理標籤，JSON 匯出、匯入並合併、匯入並取代、清除全部；也可以在這裡關閉「在聊天室顯示」。
- 對應方式：以頻道 ID (UC…) 優先記錄觀眾，讀不到時使用 @handle；觀眾更改 @handle 後，以頻道 ID 記錄的筆記仍對應同一人。
- 適用範圍：觀眾筆記只在直播聊天室（含聊天重播、彈出式聊天室、直播控制室內的聊天室）顯示，影片留言區只有暱稱還原。

## 安裝

需要 Chrome 或 Edge 111 以上版本。

1. 把 zip 解壓縮到一個固定的資料夾（之後不要搬移或刪除）。
2. 在網址列輸入 chrome://extensions（Edge 為 edge://extensions）。
3. 開啟右上角的「開發人員模式」。
4. 按「載入未封裝項目」，選擇解壓縮後含有 manifest.json 的資料夾。
5. 重新整理已開啟的 YouTube 分頁。

更新版本時，把新檔案解壓縮覆蓋到同一個資料夾，再到 chrome://extensions 按該擴充功能的重新載入按鈕，資料會保留。移除擴充功能會一併刪除本機資料，請先匯出備份。

## 設定與使用

點瀏覽器工具列的擴充功能圖示開啟彈出視窗：

- 語言：繁體中文、簡體中文、English、日本語。
- 名稱最大長度：5 到 50 個字元，預設 20。
- 過期時間：7 到 365 天，預設 15。刪除時間：必須大於過期時間且小於 730 天，預設 30。
- 雙節點替換、點擊複製連結、顯示除錯紀錄。
- 抓取頻率：普通，或慢速（遇到 YouTube 限流時使用）。
- 按鈕：📋 暱稱快取管理、🏷️ 觀眾筆記管理、📖 使用說明書、📜 關於與修改紀錄（本檔案）、🐦 回報問題。

大部分設定在儲存後需要重新整理 YouTube 分頁才會生效。觀眾筆記管理頁同時也是擴充功能的「選項」頁。

## 注意事項

- 本工具依賴 YouTube 的網頁結構，YouTube 改版時可能暫時失效；保險絲反覆熔斷時請暫停使用並回報。
- 名稱暫時無法還原通常是 YouTube 的限流，稍候幾分鐘或改用慢速抓取即可。
- 觀眾筆記存在單一瀏覽器設定檔內，不會跨裝置同步；換電腦請用管理頁的匯出與匯入。
- StreamMemo 創作者版與觀眾版是另外兩個擴充功能，會連線到 StreamMemo；本擴充功能不會。三者都會改寫同一個名稱位置，同一個瀏覽器設定檔請只啟用其中一個。
